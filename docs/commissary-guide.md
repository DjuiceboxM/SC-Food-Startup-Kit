# Commissary Guide
*SC Food Startup Kit*

## What Is a Commissary?
A commissary is a commercial kitchen supporting mobile food operations.

## Common Functions
- Food storage
- Preparation
- Water supply
- Wastewater disposal
- Warewashing

## Choosing a Commissary
Evaluate:
- Distance
- Cost
- Storage availability
- Access hours

## Agreement Records
Maintain signed agreements and renewal dates.

## Inspection Checklist
- Clean facility
- Refrigeration available
- Waste disposal procedures
- Pest control program
